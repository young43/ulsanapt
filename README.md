# 울산 아파트 경매 모아보기

대한민국 법원경매정보 공식 검색목록과 보조 공개목록에서 울산 아파트 물건을 모아, 다음 입찰일·유찰 횟수·감정가·최저가·상태를 한 화면에서 검색하는 정적 사이트입니다.

## 기본 감시 범위

- 포함: 울산 중구·남구·북구(송정동 포함)
- 제외: 동구·울주군
- 관심 면적: 공개목록의 건물 24~40평
- 우선 조건: 공급 32평 이상, 초등학교 실제 도보 10분 이내, 500세대 이상 대단지
- 추적: 공식목록의 유찰 횟수와 다음 매각기일을 사건·주소 단위로 합쳐 재매각 물건을 우선 정렬

공개목록에는 전용면적·공급면적·학교·세대수·권리·임차인 정보가 모두 제공되지 않을 수 있습니다. 따라서 사이트는 확인되지 않은 내용을 추정하지 않고 `확인 필요`로 표시합니다.

## 실행

```powershell
cd C:\workspace\NaverBlog\ulsanapt
python -m pip install -r requirements.txt
python collect.py
python build_site.py
```

생성 결과는 `site/index.html`과 `docs/index.html`입니다. `docs` 폴더를 GitHub Pages의 배포 폴더로 사용할 수 있습니다.

최근 일정목록을 더 넓게 확인하려면:

```powershell
python collect.py --history-days 120 --delay 0.08
python build_site.py
```

## 유찰·재매각 추적

법원 공식 상세검색은 서버가 허용하는 다음 14일 범위에서 아파트를 조회하고, `yuchalCnt`(유찰 횟수), `maeGiil`(다음 매각기일), `notifyMinmaePrice1`(최저매각가격)을 저장합니다. 과거 일정은 최근 일정목록과 사건·주소를 기준으로 합쳐 회차 이력으로 표시합니다.

공식 검색목록에 아직 다음 기일이 공개되지 않은 사건은 다음 갱신 때 확인되므로, 사이트의 `다음 입찰일`과 법원 사건 상세를 함께 확인해야 합니다.

## 초보자용 위험·임차인 표시

각 물건의 상세 화면에는 다음 항목을 자동 표시합니다.

- `임차인 정보`: 임차권·임대차보증금·대항력 등 공식 비고 문구가 있으면 표시하고, 없으면 `정보 미확인`으로 표시합니다. 정보 미확인은 임차인이 없다는 뜻이 아닙니다.
- `점유 상태`: 공개자료에서 점유 관련 문구가 있는지와 실제 점유를 현황조사서·현장에서 확인해야 하는지를 표시합니다.
- `주의 수준`: 유찰·재매각, 임차권·보증금, 압류·근저당 등 공개 문구를 기준으로 한 참고 표시입니다. 법률상 권리분석 결과가 아닙니다.
- `초보자 주의사항`: 매각물건명세서, 현황조사서, 등기사항증명서, 현장·관리사무소에서 확인할 항목을 물건별로 보여줍니다.
- 법원 상세에서 확인되는 사건 유형·청구금액·권리 참고문구도 함께 표시하지만, 청구금액이 낙찰자가 부담할 금액이라는 뜻은 아닙니다.

임차인의 대항력·우선변제권은 주택 인도, 전입신고, 확정일자, 배당요구 시점 등에 따라 달라질 수 있습니다. 기본 개념은 [찾기쉬운 생활법령정보의 대항력·우선변제권 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=2&cciNo=3&cnpClsNo=1&csmSeq=629)에서 확인할 수 있습니다.

## 데이터 출처와 주의사항

- 최종 확인: [대한민국 법원경매정보](https://www.courtauction.go.kr/)
- 공식 일정 검색: [법원경매정보 검색 응답](https://www.courtauction.go.kr/pgj/pgjsearch/searchControllerMain.on)
- 수집 보조: [위너옥션 공개 검색목록](https://www.winnerauction.co.kr/search/search_list.php?acourt=411&acharge=10&usage_codes=101)

공개 검색목록은 보조 자료입니다. 입찰 전 사건 상세, 매각물건명세서, 현황조사서, 등기사항증명서와 현장을 직접 확인해야 합니다.

최근 실거래가 대비 할인율은 단지명·면적 매칭 오류를 피하기 위해 현재 자동 확정하지 않습니다. 상세 화면에는 연동 대기 상태를 표시하고, 최종 확인은 [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/pt/gis/gis.do?mobileAt=&srhThingSecd=C)에서 하도록 구성했습니다.
## 온비드 공매

온비드 공식 조건검색에서 울산광역시 중구·남구·북구의 주거용 건물을 조회해 법원경매와 함께 표시합니다. 온비드 관리번호, 입찰마감일, 감정가, 최저입찰가, 건물면적, 온비드 원문 링크를 함께 저장합니다.

온비드의 기타주거용건물 중 공동주택으로 확인되는 물건도 누락을 줄이기 위해 포함합니다. 전용면적·공급면적, 공고문·감정평가서·권리관계는 입찰 전에 온비드 원문에서 최종 확인해야 합니다.
